# 🔒 ProofLock

**ProofLock** — это desktop-приложение на C++, которое блокирует отвлекающие приложения (игры, лаунчеры) до тех пор, пока пользователь не выполнит задачу и не подтвердит это.

## 🚀 Идея

Если ты тратишь слишком много времени на игры или прокрастинацию, ProofLock заставляет тебя **заработать доступ**.

> ❗ Нет доказательства → нет доступа

---

## ⚙️ Возможности (MVP)

* 🔍 Мониторинг запущенных процессов
* ⛔ Автоматическое закрытие запрещённых приложений
* 🔑 Разблокировка по коду
* 🔁 Проверка каждые N секунд
* 📂 Конфигурация списка процессов

## 🛠️ Установка и запуск

### Требования:

* Windows
* Компилятор C++ (MSVC / MinGW)

### Запуск:

1. Склонировать репозиторий:

```
git clone https://github.com/your-username/prooflock.git
```

2. Открыть проект в Visual Studio

3. Запустить от имени администратора
